Cordis Context 生命周期速查

从插件加载到卸载，只记住一条所有权链。

所有权链

root.plugin(plugin)
  → create child Context
  → root.effect(() => () => child.dispose())
  → plugin(childCtx)
  → childCtx.effect(...) 收集 disposer
  → root.dispose()
  → child.dispose()
  → 逆序执行 disposer

三个核心操作

ctx.effect(() => {
  const resource = acquire()
  return () => release(resource)
})

const child = root.plugin((childCtx) => {
  // 注册到 childCtx 的生命周期
})

child.dispose()

边界

  • Context 只管理登记过的副作用。
  • Mini 版的树由“父 disposer 持有子 dispose”构造，不需要 parent 字段。
  • 每个子插件拥有独立 Context/Fiber。
  • 父 Fiber 持有子 Fiber 的 disposer。
  • 卸载时逆序取出 disposer，即使某项失败也应继续清理。
  • provide()、on() 等 API 能自动卸载，是因为它们内部使用 effect。
