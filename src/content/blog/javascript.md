## 面试准备(面试前复习一下基础知识点)

### 1. 原型链
js对外是一门比较摇摆的语言。面向对象火的时候，js就说自己是面向对象的；函数式火的时候，js就说自己是函数式的。  
要宣称自己是面向对象的，那就要有三个要素：
- 封装
- 继承
- 多态
要宣称自己是函数式的，那么函数就要是一等公民。  

这两点js其实都符合。

面向对象中的封装，就是将数据和方法封装在一起，形成一个`对象`。
面向对象中的继承，就是子类继承父类的方法和属性。
面向对象中的多态，就是子类可以重写父类的方法。

继承有两种选择，一是`类继承`，二是`原型继承`。js就是选择的原型继承，早期js选择原型继承的理由也比较简单————这个方案实现起来比较简单。

```js
function Animal() {
  this.name = 'animal';
}

function Dog() {
  this.name = 'dog';
}

Dog.prototype = new Animal();

var dog = new Dog();
console.log(dog.name); // dog
```

原型继承的思路也比较简单，就是将子类的原型对象指向父类的实例。这样子类就可以继承父类的方法和属性。我们简单说明一下原型继承的实现：  
首先，js支持函数作为构造函数，通过`new`关键字可以创建一个对象。每一个函数都有一个`prototype`属性，这个属性就是函数的原型对象。当我们new一个函数时，会创建一个对象，这个对象其实就"拷贝"自这个原型对象。  
拷贝有两种基本方案：
- 写复制，将原型对象整个复制，然后赋值给新对象。这个方案简单，但是很消耗空间。
- 读遍历，我们先创建一个空对象，运行完new的创建流程之后。在读取这个对象的某个属性或者方法的时候，如果这个属性或者方法不存在，就从原型对象中读取。这个方案比较消耗性能。

js选择了读遍历的方案。原因也很简单，js的原型访问都比较短，性能损失可以忽略不计。  
在读遍历的时候，遵循一下规则即可：
- 优先访问对象自身的属性或者方法
- 如果对象自身的属性或者方法不存在，就从原型对象中读取
- 如果原型对象中也不存在，就返回undefined（关于undefined我们后面讲）

这就是js原型链的基本内容。

如果说有什么特殊的：
```js
console.log(Object.prototype.__proto__); // null
Function.prototype.__proto__ === Object.prototype; // true
```
这两个也比较好理解
1. Object.prototype.__proto__ === null，这个比较简单，就是原型链的终点。并且我们本来也知道 typeof null === 'object'，这一点也算是被js给圆回来了。
2. Function.prototype.__proto__ === Object.prototype，这个也比较好理解，因为所有的prototype属性本身也是一个对象，所以它的原型对象就是Object.prototype。

### 2. 闭包
我们经常听到一个观点：当js中函数嵌套的时候，内层函数可以访问外层函数的变量。这就是闭包。  
这个观点其实是有问题的，因为js中函数嵌套的时候，内层函数可以访问外层函数的变量，这个是js的语法特性，并不是闭包。  
闭包的本质就是：当一个函数被创建时，它会携带一个`词法作用域`，这个作用域包含了函数定义时所处的环境。当函数被调用时，它会使用这个作用域中的变量。  也就是说 函数+环境 就构成了闭包。  

我们更进一步理解: 
> 闭包本质上就是js语言的环境管理的基础组件，并不是函数访问外部而构成了闭包，而是因为有闭包这种基础组件，js的函数才能访问外部变量。
